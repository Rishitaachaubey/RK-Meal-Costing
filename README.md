# RK Group Production Control (Next.js)
Start: `npm install`, `npm run build`, `npm run start` -> http://localhost:3000  (Node.js 20+). Or run start.bat on Windows.
Data: data/db.json (created on first run; back it up). Data saved by older versions is migrated automatically.
First use: Meal demand > "Import data" > load Howrah workbook data or the 3 demo items.
